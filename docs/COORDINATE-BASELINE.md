# Coordinate Toolkit V1 坐标算法基线

> 阶段：V1 Phase 2-A Task 1  
> 目的：在实现 `CoordinateService` 前冻结 WGS84、GCJ02、BD09 的旧项目转换行为  
> 范围：测试与行为基线；不包含生产服务、页面、Point 缓存、地图或投影坐标

## 1. 依赖基线

`reference/map-tools/package.json` 将 `gcoord` 声明为：

```text
^0.3.2
```

`reference/map-tools/package-lock.json` 中实际锁定的信息为：

| 项目 | 值 |
|---|---|
| 包名 | `gcoord` |
| 声明版本 | `^0.3.2` |
| 实际锁定版本 | `0.3.2` |
| 完整性摘要 | `sha512-LwhA+ev6fBXadAFprI+Q593TTC1QYa0Quewd3YUT51wQS2S6gekrC1YCQlJhKA8HpqCF+dX+fBcX/lkYM5Kgog==` |
| 许可证 | MIT |

本项目为基线测试精确固定 `gcoord@0.3.2`，不使用版本范围。后续如升级依赖，应先运行本基线并审查输出变化，不能自动接受快照更新。

## 2. 样本来源

基线输入采用：

```text
WGS84: 121.4737, 31.2304
```

该坐标来自参考项目已有的上海地图中心配置：

- `reference/map-tools/src/utils/mapUtils.ts`
- `reference/map-tools/src/components/MapRenderer.tsx`

新项目既有 Domain 测试也使用相同坐标，因此它适合作为迁移回归样本。

此样本只用于冻结 `map-tools + gcoord@0.3.2` 的计算行为，不是测绘控制点，也不能单独证明算法的绝对精度。正式精度结论仍需可信外部样本或业务验收点支持。

## 4. 误差标准

### 4.1 输出稳定性

固定输出允许误差：

```text
1 × 10^-10 度
```

该阈值用于发现依赖版本、组合顺序或实现行为的变化，不代表产品对用户承诺的测绘精度。

### 4.2 往返误差

以下三组往返转换允许误差：

```text
每个经纬度分量 ≤ 2 × 10^-6 度
```

覆盖：

- WGS84 → GCJ02 → WGS84
- GCJ02 → BD09 → GCJ02
- WGS84 → BD09 → WGS84

该阈值覆盖当前样本在 `gcoord@0.3.2` 下的往返误差，同时足够严格地发现明显退化。它仍是工程回归阈值，不是测绘精度认证。

## 5. 失败行为基线

测试明确要求以下输入失败：

- 非有限数值：`NaN`、`Infinity`
- 经度超出 `[-180, 180]`
- 纬度超出 `[-90, 90]`

失败结果必须：

- 明确标识为 `INVALID_COORDINATE`；
- 不包含转换坐标；
- 不使用 `(0, 0)` 作为错误占位。

当前测试中的校验与结果包装仅是测试基线夹具，不是 `CoordinateService` 实现。后续服务必须满足同一失败语义。

## 6. 测试文件

| 文件 | 职责 |
|---|---|
| `tests/coordinate/baseline/coordinate-baseline.fixtures.ts` | 固定依赖版本、样本、输出和误差阈值 |
| `tests/coordinate/baseline/coordinate-baseline.test.ts` | 验证六条转换、三组往返误差及非法输入行为 |

测试直接调用 `gcoord`，并只在测试内复现旧项目的两条固定组合路径：

```text
WGS84 → GCJ02 → BD09
BD09 → GCJ02 → WGS84
```

没有复制旧 `useCoordTransform`，也没有引入 `TransformationGraph`、`AlgorithmRegistry` 或动态注册机制。

## 7. 基线使用规则

后续实现 `CoordinateService` 时：

1. 服务测试应复用同一组夹具；
2. 服务输出必须通过六条固定转换测试；
3. 非法输入不得产生 `(0, 0)`；
4. 修改转换顺序或依赖版本必须显式更新本文；
5. 更新固定输出前必须说明原因并评估现有 Point 转换缓存是否失效；
6. 本基线不允许扩展为上海 2000、CGCS2000 或地图 SDK 测试。

## 8. 当前风险

- 只有一个上海区域样本，足以冻结当前行为，但不足以证明全国范围表现。
- 样本不是权威测绘控制点，不能用于对外宣称绝对精度。
- `gcoord@0.3.2` 是旧版本；升级可能修复问题，也可能改变既有输出。
- GCJ02 逆转换和多步往返不是严格可逆，必须保留误差容差。
- 境外坐标、边界区域和更多城市尚未建立基线。
- 当前非法输入规则是 V1 期望契约，不代表 `gcoord` 自身会拒绝所有非法输入。
- 上海 2000、CGCS2000 仍未进入本基线，不能因这些测试通过而启用。
